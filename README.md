## Projetos em destaque

### FoodReviewAI
**Análise de sentimentos com Machine Learning**

Uma aplicação capaz de identificar avaliações positivas e negativas de restaurantes. Trabalhei com mais de 16 mil avaliações reais, treinei e comparei dois modelos, incluindo o BERTimbau, que alcançou **97,64% de acurácia** nos testes.

O projeto inclui API, modelos publicados no Hugging Face, testes automatizados e uma interface disponível online.

**Tecnologias:** Python, scikit-learn, PyTorch, BERTimbau, FastAPI e Streamlit.

[💻 Código no GitHub](https://github.com/felipemtrindade/FoodReviewAI) · [🌐 Testar aplicação](https://foodreviewai.streamlit.app/)

### DocumentAnalysisAI
**Converse com seus documentos usando IA**

Uma ferramenta que permite enviar documentos PDF e fazer perguntas sobre seu conteúdo. A aplicação encontra as informações relacionadas, utiliza IA para elaborar respostas e mostra as páginas consultadas.

Desenvolvi o projeto para explorar como modelos de linguagem podem ser integrados a sistemas de busca e análise de documentos.

**Tecnologias:** Python, RAG, ChromaDB, Gemini e Streamlit.

[💻 Código no GitHub](https://github.com/felipemtrindade/DocumentAnalysisAI) · [🌐 Testar aplicação](https://documentanalysisaifrmt.streamlit.app/)

### 📊 Avaliação de Machine Learning - AV1
**Previsão de faixas de renda**

Projeto acadêmico em que trabalhei com aproximadamente 49 mil registros para treinar um modelo capaz de prever faixas de renda. O modelo alcançou **81,79% de acurácia**, e suas previsões podem ser acessadas por uma API.

**Tecnologias:** Python, Pandas, scikit-learn, Random Forest, Flask e Docker.

[💻 Ver projeto](https://github.com/felipemtrindade/avaliacao-ml-av1)

### Plataforma de Monitoramento para DevOps
**Monitoramento de redes e serviços**

Projeto acadêmico desenvolvido em dupla para acompanhar serviços de rede, identificar falhas e visualizar métricas de desempenho.

A plataforma conta com dashboards, alertas e simulações de eventos de segurança, aproximando conceitos de redes de situações reais de operação.

**Tecnologias:** Laravel, React, MySQL e Chart.js.

[💻 Ver projeto](https://github.com/felipemtrindade/Plataforma-de-Monitoramento-para-DevOps)
